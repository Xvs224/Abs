# 毕业论文质量监控系统 — 异常情况与判定标准

> 本文档列出系统全链路（选题 → 开题 → 中期 → 论文 → 评阅 → 答辩 → 归档）中可能出现的所有异常情况，以及对应的判定标准与处理建议，供开发、测试、运维与管理员参考。

---

## 一、通用判定原则

| 编号 | 原则 | 说明 |
|------|------|------|
| G-01 | 状态机完整性 | 每条业务数据必须处于其模型定义的合法状态集合内，不得出现未定义状态值。 |
| G-02 | 分数范围合法 | 所有分数字段必须在 `[0, 100]` 区间内（或业务定义的子区间），`None`/`null` 仅在"未评分"状态下允许。 |
| G-03 | 角色权限一致 | 操作人与数据归属/角色权限必须匹配，越权操作视为异常。 |
| G-04 | 时序一致性 | 后序阶段数据的存在以前序阶段完成为前提（如存在归档则必须存在答辩记录）。 |
| G-05 | 文件可访问性 | 已记录的文件路径必须在存储中真实存在且可读，否则下载必然失败。 |
| G-06 | 幂等性 | 同一状态下重复提交/审核不应产生副作用或脏数据。 |

## 二、选题管理（Topic）

### 状态集合
`available`（可选）/ `pending`（待审核）/ `approved`（已通过）/ `rejected`（已驳回）/ `withdrawn`（已下架）

| 编号 | 异常情况 | 判定标准 | 处理建议 |
|------|----------|----------|----------|
| T-01 | 选题状态非法 | `status` 不在上述集合内 | 数据修复为最近一个合法状态；排查写入逻辑。 |
| T-02 | 教师选题未发布即被选 | `source_type='teacher'` 且 `status='available'` 但 `publish_time` 为空 | 补全 `publish_time` 或将状态置为 `pending`。 |
| T-03 | 学生选题被驳回后未退回 | `source_type='student'` 且 `status='rejected'` 但 `reject_reason` 为空 | 补全驳回原因，便于学生重交。 |
| T-04 | 选题归属缺失 | `student_id` 为空且 `source_type='student'` | 视为孤儿数据，管理员删除或补全归属。 |
| T-05 | 选题重复 | 同一学生同一学年存在多条 `status` 非 `withdrawn` 的选题 | 保留最新一条，其余置为 `withdrawn`。 |
| T-06 | 已通过选题缺少指导教师 | `status='approved'` 但 `teacher_id` 为空 | 补全指导教师或退回审核。 |
| T-07 | 管理员删除/重交越权 | 非 admin 角色调用删除/重交接口 | 接口层返回 403；服务层二次校验角色。 |

## 三、开题报告（Proposal）

### 状态集合
`draft`（草稿）/ `submitted`（已提交）/ `approved`（已通过）/ `rejected`（已驳回）

| 编号 | 异常情况 | 判定标准 | 处理建议 |
|------|----------|----------|----------|
| P-01 | 状态非法 | `status` 不在集合内 | 修复状态。 |
| P-02 | 已提交但无选题关联 | `topic_id` 为空且 `status != 'draft'` | 补全选题或退回草稿。 |
| P-03 | 已通过但无审核意见 | `status='approved'` 且 `review_comment` 为空 | 补全审核意见。 |
| P-04 | 已驳回但无驳回原因 | `status='rejected'` 且 `reject_reason` 为空 | 补全驳回原因。 |
| P-05 | 重复提交 | 同一学生存在多条 `status='submitted'` 的开题报告 | 保留最新，其余置为 `draft` 或删除。 |
| P-06 | 审核时间早于提交时间 | `review_time < submit_time` | 修正时间戳。 |
| P-07 | 已通过开题但选题未通过 | `proposal.status='approved'` 但关联 `topic.status != 'approved'` | 选题应先通过；管理员可强制重置选题状态。 |

## 四、中期检查（MidtermCheck）

### 状态集合
`draft` / `form_submitted`（已提交表格）/ `guided`（已指导）/ `ppt_submitted`（已提交PPT）/ `pass`（通过）/ `failed`（不通过）/ `rectifying`（整改中）/ `rectified`（已整改）

### 分数字段
`teacher_score`（指导教师评分）、`check_group_score`（检查组评分）、`final_score`（最终成绩）

| 编号 | 异常情况 | 判定标准 | 处理建议 |
|------|----------|----------|----------|
| M-01 | 状态非法 | `status` 不在集合内 | 修复状态。 |
| M-02 | 分数越界 | 任一分数字段不在 `[0, 100]` | 修正分数。 |
| M-03 | 已通过但最终成绩为空 | `status='pass'` 且 `final_score` 为空 | 补全最终成绩。 |
| M-04 | 最终成绩与子成绩不一致 | `final_score` 与 `teacher_score`/`check_group_score` 权重计算结果偏差 > 1 | 按权重公式重算。 |
| M-05 | 整改中但无整改要求 | `status='rectifying'` 且无关联整改记录 | 补全整改要求或退回上一状态。 |
| M-06 | 已整改但无复检结果 | `status='rectified'` 且未关联复检通过记录 | 触发复检流程。 |
| M-07 | 状态跳跃 | 从 `draft` 直接跳到 `pass`/`failed` 而未经过 `form_submitted` | 按状态机回退或补全中间记录。 |
| M-08 | 同一学生多条活跃中期记录 | 同一学生同一学年存在多条非 `draft` 状态的中期记录 | 保留最新一条，其余置为 `draft`。 |

## 五、论文管理（ThesisVersion）

### 格式检测状态
`format_check_status`: `pending` / `done` / `failed`

### 分数字段
`format_score`（格式规范得分）

| 编号 | 异常情况 | 判定标准 | 处理建议 |
|------|----------|----------|----------|
| TH-01 | 论文文件缺失 | `file_path` 指向的文件在存储中不存在 | 重新上传或标记为损坏。 |
| TH-02 | 格式检测完成但无分数 | `format_check_status='done'` 且 `format_score` 为空 | 重新执行格式检测。 |
| TH-03 | 格式检测失败但仍可提交 | `format_check_status='failed'` 但版本被标记为可归档 | 拦截归档，要求重新检测。 |
| TH-04 | 版本号倒退 | 同一论文的新版本 `version_no` 小于历史最大版本号 | 重新分配版本号。 |
| TH-05 | 同一版本重复上传 | 同一学生同一论文存在内容完全相同的多个版本 | 去重，保留最新。 |
| TH-06 | 删除非本人版本 | 非 owner/教师调用删除接口 | 接口返回 403。 |

## 六、评阅管理（Review）

### 状态集合
`pending`（待评阅）/ `completed`（已完成）

### 分数字段
`topic_score` / `content_score` / `method_score` / `innovation_score` / `format_score` / `total_score`

| 编号 | 异常情况 | 判定标准 | 处理建议 |
|------|----------|----------|----------|
| R-01 | 评阅分配缺失评阅人 | `reviewer_id` 为空 | 补全评阅人或删除分配。 |
| R-02 | 已完成但总分空 | `status='completed'` 且 `total_score` 为空 | 重新计算或补录总分。 |
| R-03 | 总分与子分不一致 | `total_score != Σ(子项 × 权重)` 且偏差 > 1 | 按权重公式重算。 |
| R-04 | 子项分数越界 | 任一子项分数不在 `[0, 100]` | 修正分数。 |
| R-05 | 评阅意见为空 | `status='completed'` 且 `comment` 为空 | 补全评阅意见。 |
| R-06 | 重复评阅分配 | 同一论文同一评阅人存在多条 `pending`/`completed` 记录 | 保留最新，其余删除。 |
| R-07 | 评阅人评阅自己指导的论文 | `reviewer_id == topic.teacher_id`（若业务禁止） | 重新分配评阅人。 |

## 七、答辩管理（Defense）

### 状态集合
`scheduled`（已安排）/ `in_progress`（进行中）/ `completed`（已完成）

### 分数字段
`presentation_score`（陈述）/ `qa_score`（问答）/ `thesis_quality_score`（论文质量）/ `total_score`（总分）

### 结果字段
`grade`（等级：excellent/good/medium/pass/fail 等）、`result`（结果描述）

| 编号 | 异常情况 | 判定标准 | 处理建议 |
|------|----------|----------|----------|
| D-01 | 答辩已完成但总分为 0 或空 | `status='completed'` 且 (`total_score` 为空或 `total_score == 0`) | **已修复**：归档服务需关联 Defense 表取分；确认 `score_defense` 已写入。 |
| D-02 | 答辩结果不显示 | `status='completed'` 但 `result` 或 `grade` 为空 | **已修复**：前端根据 `final_grade`/`defense_result` 渲染；后端 `_enrich_archive` 需注入 `defense_result`。 |
| D-03 | 总分与子分不一致 | `total_score != presentation_score + qa_score + thesis_quality_score` | 按公式重算。 |
| D-04 | 等级与总分不匹配 | 总分 ≥ 90 但 grade 非 excellent；总分 < 60 但 grade 非 fail 等 | 按等级映射规则重算 grade。 |
| D-05 | 答辩时间非法 | `defense_time` 早于论文提交时间或晚于当前时间且状态为 completed | 修正时间。 |
| D-06 | 答辩委员会为空 | `committee_members` 为空但已安排 | 补全委员会成员。 |
| D-07 | 未答辩即归档 | 归档记录存在但无对应 Defense 记录 | 拦截归档或补录答辩。 |

## 八、成果归档（Archive）

### 状态集合
`pending`（待审核）/ `archived`（已归档）/ `returned`（已退回）

### 字段
`final_score`（最终成绩）、`final_grade`（最终等级）、`defense_result`（答辩结果）

| 编号 | 异常情况 | 判定标准 | 处理建议 |
|------|----------|----------|----------|
| A-01 | 已归档但最终成绩为 0 | `status='archived'` 且 `final_score` 为空或 0 | **已修复**：从 Defense 表回填 `total_score`。 |
| A-02 | 已归档但答辩结果为空 | `status='archived'` 且 `defense_result` 为空 | **已修复**：从 Defense 表回填 `result`。 |
| A-03 | 最终等级与成绩不匹配 | `final_grade` 与 `final_score` 区间映射不一致 | 按映射表（≥90 excellent / 80-89 good / 70-79 medium / 60-69 pass / <60 fail）重算。 |
| A-04 | 退回但无退回原因 | `status='returned'` 且 `return_reason` 为空 | 补全退回原因。 |
| A-05 | 归档文件缺失 | 关联文件在存储中不存在 | 重新上传或标记异常。 |
| A-06 | 重复归档 | 同一学生同一论文存在多条 `pending`/`archived` 归档 | 保留最新，其余退回或删除。 |
| A-07 | 未通过答辩即归档 | `final_score < 60` 但 `status='archived'` | 退回重新答辩。 |

## 九、文件下载与存储

| 编号 | 异常情况 | 判定标准 | 处理建议 |
|------|----------|----------|----------|
| F-01 | 下载接口 404 | 接口路径不匹配（`/api/files/download?path=...` 未注册） | **已修复**：确保 `files.py` 注册 path 下载路由。 |
| F-02 | 下载 401 未授权 | 请求未携带有效 Bearer token | 前端统一使用 `userStore.token` 注入 header。 |
| F-03 | 文件物理不存在 | `path` 指向文件在 `uploads/` 下不存在 | 返回 404 + 提示文件已被清理。 |
| F-04 | 路径穿越 | `path` 含 `../` 或绝对路径逃逸 uploads 目录 | 后端校验路径必须在 uploads 根目录内，否则 400。 |
| F-05 | 文件名为空/非法 | 上传文件名空或扩展名不在白名单 | 拦截上传，返回 400。 |
| F-06 | 文件大小超限 | 上传文件超过配置上限 | 拦截上传，返回 413。 |
| F-07 | 下载文件名乱码 | `Content-Disposition` 未对中文 filename 做 RFC 5987 编码 | 使用 `filename*=UTF-8''<encoded>` 格式。 |

## 十、权限与角色

| 编号 | 异常情况 | 判定标准 | 处理建议 |
|------|----------|----------|----------|
| ACCESS-01 | 学生访问他人数据 | `current_user.role='student'` 且操作数据的 `student_id != current_user.id` | 返回 403。 |
| ACCESS-02 | 教师审核非自己指导的选题 | `teacher_id != current_user.id` | 返回 403 或限制数据范围。 |
| ACCESS-03 | 非管理员调用管理员接口 | 角色非 admin 调用用户管理、全局删除等接口 | 返回 403。 |
| ACCESS-04 | 管理员删除/重交越权 | 管理员删除已归档/已通过数据未做状态校验 | 服务层对管理员也保留必要状态限制（如已归档需先退回）。 |
| ACCESS-05 | Token 过期/失效 | JWT 过期或在黑名单中 | 返回 401，前端跳转登录。 |
| ACCESS-06 | 越权查看敏感字段 | 学生端接口返回了教师评分、审核意见等 | 响应层按角色裁剪字段。 |

## 十一、数据一致性（跨模块）

| 编号 | 异常情况 | 判定标准 | 处理建议 |
|------|----------|----------|----------|
| C-01 | 孤儿开题报告 | `proposal.topic_id` 指向的 topic 不存在 | 补建选题或删除开题。 |
| C-02 | 孤儿中期检查 | `midterm.proposal_id` 指向不存在 | 删除或补建。 |
| C-03 | 孤儿归档 | `archive.thesis_id` 指向不存在 | 删除或补建。 |
| C-04 | 前序未通过后序已完成 | 开题 rejected 但中期已 pass | 回退后序或强制通过前序。 |
| C-05 | 评阅/答辩缺失但已归档 | 归档存在但无 Review 或 Defense 记录 | 补录或退回归档。 |
| C-06 | 分数链断裂 | 归档 `final_score` 与 Defense `total_score` 不一致 | 以 Defense 为准回填归档。 |

## 十二、前端展示异常

| 编号 | 异常情况 | 判定标准 | 处理建议 |
|------|----------|----------|----------|
| UI-01 | 答辩成绩显示 0 | 归档列表 `final_score` 列显示 0 | **已修复**：后端 `_enrich_archive` 关联 Defense 取 `total_score`。 |
| UI-02 | 答辩结果不显示 | 等级/结果列为空 | **已修复**：`ArchiveResponse` 增加 `defense_result`；前端 `finalGradeLabel` 含 medium 映射。 |
| UI-03 | 下载按钮无响应 | 点击下载无任何反馈 | 检查 `handleDownload` 是否绑定、token 是否注入。 |
| UI-04 | 管理员无删除/重交按钮 | admin 角色下操作列缺少按钮 | **已修复**：各模块 `v-if="isAdmin"` 展示删除/重交。 |
| UI-05 | 列表数据不刷新 | 操作成功后列表未更新 | 操作回调中调用 `loadList()`。 |
| UI-06 | 状态标签颜色错误 | 状态文本与 tag type 不匹配 | 统一 `statusTagType` 映射。 |

## 十三、异常等级与处理 SLA

| 等级 | 定义 | 响应时间 | 示例 |
|------|------|----------|------|
| P0 | 核心功能不可用（登录、上传、下载、归档） | 立即 | 文件下载 404、登录失败 |
| P1 | 数据丢失/不一致、成绩错误 | 2 小时 | 归档成绩为 0、答辩结果丢失 |
| P2 | 权限越界、状态非法 | 1 个工作日 | 学生可删除他人数据 |
| P3 | 展示类问题、轻微体验 | 3 个工作日 | 标签颜色错误、文案不统一 |
